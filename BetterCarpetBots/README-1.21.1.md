# Better Carpet Bots для Minecraft 1.21.1

Неофициальный перенос версии 1.1.0 на Fabric / Minecraft 1.21.1.
Исходник: https://github.com/matejstastny/better-carpet-bots
Тег исходной версии: v1.1.0+1.21.11; commit c2a1570.
Лицензия MIT, автор исходного мода Matej Stastny.

## Установка

1. Установите Minecraft 1.21.1 с Fabric Loader и Java 21.
2. Установите Carpet для 1.21/1.21.1 (проверенная версия: 1.4.147).
3. Удалите старый JAR Better Carpet Bots и поместите новый JAR в папку mods.

Mod Menu 11.0.5 для 1.21.1 необязателен и добавляет экран настройки скина.
Fabric API самому этому моду не требуется.
Команды скинов, как и в исходнике, вызывают внешнюю команду skin set web slim;
для них нужен совместимый мод, предоставляющий эту команду.

## Перенос

- Minecraft/Yarn, Carpet и Mod Menu заменены на версии для 1.21.1.
- Права команд перенесены на hasPermissionLevel и withLevel.
- Выбранный слот инвентаря использует API 1.21.1.
- Фильтр брони использует getPreferredEquipmentSlot; один предмет в слоте.
- Фон экрана настройки адаптирован под Screen API 1.21.1.
- Сохранены команды, инвентарь ботов, команда игроков bots, конфигурация
  и ресурсы исходной версии.

## Сборка

Нужен JDK 21. Из корня проекта запустите ./gradlew build
(на Windows: gradlew.bat build). Готовый файл — в build/libs.

## Проверка

Сборка Gradle завершилась успешно. В отдельном сервере Minecraft 1.21.1 /
Fabric Loader 0.16.14 / Carpet 1.4.147 выполнено 29 проверок через консоль
и 88 интеграционных проверок через временный проверочный мод.
Проверены создание/удаление ботов, все уровни доступа, управление, реальное
использование щита, добыча блока, прыжок, обмен руками и выбрасывание предметов,
живой инвентарь, перенос предметов и фильтрация брони/элитр/тыквы.
Проверочный мод и тестовый мир в эту поставку не входят.
Графическое отображение экрана Mod Menu проверено по API и компиляции;
интерактивный клиентский запуск не выполнялся.
