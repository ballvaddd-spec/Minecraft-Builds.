## Скачать и установить

Готовый проверенный файл: [better-carpet-bots-1.1.0+mc1.21.1.jar](../mods/better-carpet-bots-1.1.0+mc1.21.1.jar?raw=1).
Контрольная сумма SHA-256 — в [файле SHA-256](../mods/better-carpet-bots-1.1.0+mc1.21.1.jar.sha256).

1. Установите Minecraft **1.21.1**, [Fabric Loader](https://fabricmc.net/use/installer/) **≥ 0.15.0** и **Java 21**. Проверенная версия загрузчика — **0.16.14**.
2. Установите [Carpet](https://modrinth.com/mod/carpet) для 1.21/1.21.1. Проверенная версия — **1.4.147**.
3. Удалите старый JAR Better Carpet Bots из папки `mods` и поместите туда новый файл.
4. Для сервера установите мод в серверную папку `mods`. В одиночной игре установите его в папку `mods` своего клиента.

Fabric API самому этому моду не требуется. Необязательный [Mod Menu](https://modrinth.com/mod/modmenu) **11.0.5** добавляет экран настройки скина на клиенте.
Команды скинов используют внешнюю команду `skin set web slim`; для работы скинов нужен совместимый дополнительный мод, который предоставляет эту команду.

## Создать бота

Выполните в чате игры:

```mcfunction
/bot spawn SteveBot
```

Бот появится на вашей позиции в режиме выживания. Без имени команда `/bot spawn` создаёт `Bot1`, `Bot2` и так далее.
Имя должно содержать от 1 до 16 латинских букв, цифр или символов `_`. Нельзя использовать имя игрока, уже находящегося на сервере, или имя, которое мод сохранил как принадлежащее настоящему игроку.

Команда создания требует контекст игрока: из серверной консоли можно вызвать её через `execute as <имя_игрока> at @s run bot spawn SteveBot`.
По умолчанию `/bot` доступна всем игрокам. Оператор может изменить требуемый уровень доступа командой `/bots permissionLevel <0–4>`; команды `/bots` требуют уровня 2.

Примеры управления:

```mcfunction
/bot SteveBot attack
/bot SteveBot attack stop
/bot SteveBot inventory
/bot SteveBot stop
/bot SteveBot kill
/bots list
```

Инвентарь открывается, если вы находитесь не дальше 10 блоков от бота.
Полная таблица сохранённых команд находится в [исходном README](README-upstream.md).

## Собрать из исходников

Нужен **JDK 21**. В корне проекта выполните:

```sh
./gradlew build
```

В Windows: `gradlew.bat build`. Готовый мод появится в `build/libs/better-carpet-bots-1.1.0+mc1.21.1.jar`.
Gradle Wrapper использует Gradle 8.8; первая сборка загружает Gradle и зависимости из сети.

## Что адаптировано

- Версии Minecraft/Yarn, Carpet и Mod Menu заменены на совместимые с 1.21.1.
- Команды используют API прав `hasPermissionLevel` и `withLevel`.
- Выбор слота инвентаря, фильтрация брони и фон экрана настройки перенесены на API 1.21.1.
- Сохранены управление ботами, их инвентарь, команда игроков `bots`, конфигурация и ресурсы исходного мода.

Дополнительные сведения о переносе: [README-1.21.1.md](README-1.21.1.md).

## Проверка и ограничения

Сборка Gradle прошла успешно. На отдельном сервере **Minecraft 1.21.1 / Fabric Loader 0.16.14 / Carpet 1.4.147** выполнены **29 проверок через консоль и 88 интеграционных проверок** временным проверочным модом.
Проверены создание и удаление ботов, все уровни доступа, управление, использование щита, добыча блока, прыжок, обмен руками, выбрасывание предметов, живой инвентарь, перенос предметов и фильтрация брони, элитр и тыквы.

Интерактивный запуск клиентского интерфейса Mod Menu и загрузка скинов через сеть не проверялись. Экран настройки проверен по API и компиляции.
Временный проверочный мод и тестовый мир в эту поставку не входят; указанные проверки описывают проверку поставленного JAR и не являются встроенным набором тестов проекта.
