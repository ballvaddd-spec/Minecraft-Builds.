# Royal Rags 3D — Fabric 1.21.1

Client-side Fabric mod that replaces the worn model of all six vanilla armor tiers with custom 3D outfits.

- Leather — ragged tramp outfit / hood / patches / torn tails
- Chainmail — street fighter / cap / chain collar / shoulder details
- Iron — bodyguard / suit / sunglasses / tie / shoulder pads
- Gold — rich outfit / gold headpiece / chain / luxury shoulders
- Diamond — prince / blue-gold crown / epaulettes / cape
- Netherite — king / large crown / fur collar / royal cape / heavy shoulders

Install Minecraft Java 1.21.1 + Fabric Loader + Fabric API, then place the built jar in .minecraft/mods.
The old Royal Rags resource pack is not required. Armor stats remain vanilla.
