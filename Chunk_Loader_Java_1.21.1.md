# Chunk Loader — Java 1.21.1

Рабочий принцип: сущность или предмет проходит между связанными порталами Overworld ↔ Nether и обновляет загрузку чанков.

Рекомендованный вариант для 1.21.1: item-based Nether Portal Chunk Loader (TMC / enbyd):
https://www.shulkr.com/en/schematics/aSuzSliQaedl/item-nether-portal-chunk-loader

## Для версии 1.21.1

- Работает на Java Edition.
- Построй часть механизма в Overworld и соответствующую часть в Nether.
- Оба портала должны быть правильно связаны.
- В оба dropper нужно положить по одному предмету.
- Основной lever включает/выключает загрузчик.
- В версиях 1.19–1.21.4 механизм после полной выгрузки может требовать повторного запуска.

Источник конструкции указан выше; файл схемы из стороннего каталога в этот репозиторий не копируется без отдельного разрешения на распространение.
