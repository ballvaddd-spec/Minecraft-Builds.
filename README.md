# Minecraft Builds

Две отдельные постройки для Minecraft Java 1.21.1 и BuildHelper.

## ZIP-архивы с постройками

- **[Starter House — скачать ZIP](./Starter_House_BuildHelper.zip)** — наземный дом с двумя дверями, огородом и погребом из первого видео.
- **[AFK Creeper Farm — скачать ZIP](./AFK_Creeper_Farm_BuildHelper.zip)** — переработанная по второму видео открытая многоярусная ферма криперов над океаном. Восемь круглых платформ с деревянными люками под потолком и кнопками на полу, раздатчики для водного сброса, большой навес и стеклянная площадка сбора. В ZIP содержится файл .schem и README_RU.txt.

## Как добавить в BuildHelper

1. Скачай соответствующий ZIP.
2. Распакуй из него файл `.schem`.
3. Перемести его в `.minecraft/buildhelper/schematics/`.
4. Выбери постройку в моде BuildHelper.

## Ограничения

Постройки воссозданы по кадрам видео, а не экспортированы из исходных игровых миров. Точное совпадение каждой детали и эффективность фермы в Minecraft **не подтверждены**. Схемы проверены на уровне формата NBT и содержимого архивов, но механизмы требуют проверки в запущенной игре.
