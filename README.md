# Minecraft Builds

Постройки для Minecraft Java 1.21.1 / мода BuildHelper.

## Фермы железа

**Исправленная большая ферма железа (25 × 34 × 25):**
- [ZIP с исправленной схемой](./Auto_Iron_Farm_Java_1.21.1_FIXED.zip)
- [Файл .schem](./Auto_Iron_Farm_Java_1.21.1_FIXED.schem)

Исправлена главная ошибка водосбора: под верхним 3-блочным желобом теперь есть отдельный непрерывный канал, а вода с двух концов направляется к шахте 3 × 2. Сверху боковая вода уводит големов в продольный желоб. Исходные ссылки `Auto_Iron_Farm_Java_1.21.1.schem/.zip` тоже обновлены той же исправленной геометрией.

⚠️ **Маленькая ферма `Compact_Fast_Iron_Farm_Java_1.21.1` не проходила проверку в Minecraft.** Её водосбор может иметь проблемы; если големы застревают, не используйте её как гарантированно рабочую.

## Установка
1. Скачай ZIP нужной постройки.
2. Распакуй файл `.schem`.
3. Перенеси его в `.minecraft/buildhelper/schematics/`.
4. Выбери схему в BuildHelper.

BuildHelper не создаёт жителей и не всегда корректно переносит воду и лаву; жидкости и направление воронок нужно проверять вручную. Данные схемы проверены по геометрии/NBT и содержимому ZIP, но **практическое поведение железных големов в игре пока не тестировалось**.
