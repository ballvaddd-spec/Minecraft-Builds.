# Minecraft Builds

Схемы построек для Minecraft Java 1.21.1 / BuildHelper.

## Исправленные фермы железа (водосбор)

- [**Компактная ферма — исправленный ZIP**](./Compact_Fast_Iron_Farm_Java_1.21.1_FIXED.zip) — 19 × 18 × 15. Длинный желоб шириной 3 блока и водослив через ступень к новой шахте сбора 3 × 2; жители и зомби требуются отдельно.
- [**Большая ферма — исправленный ZIP**](./Auto_Iron_Farm_Java_1.21.1_FIXED.zip) — 25 × 34 × 25. Второй, нижний канал направляет големов к шахте 3 × 2; убраны препятствия под желобом.

Предыдущие ZIP и .schem по старым ссылкам заменены на исправленные файлы. Сами схемы остаются и отдельно как .schem с суффиксом FIXED.

### Важно

Это **исправления схем по геометрии и расположению блоков**. Файлы NBT и ZIP проходят проверку структуры, но **работа водных потоков, спавна, переноса големов, редстоуна и скорость фермы не были проверены в Minecraft**. Для уже построенной старой версии надёжнее полностью убрать старую постройку и построить исправленную заново. Жидкости, жителей и зомби BuildHelper не создаёт автоматически.

## Установка

Скачай нужный ZIP, распакуй .schem в `.minecraft/buildhelper/schematics/` и выбери схему в моде. README_RU.txt внутри архива объясняет источники воды и ручные действия.
