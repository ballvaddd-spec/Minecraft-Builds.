LITEMATICA ДЛЯ MINECRAFT JAVA 1.21.1 — FABRIC

Файлы:
Litematica_0.19.61_MC1.21.1_Fabric.jar
MaLiLib_0.21.10_MC1.21.1_Fabric.jar

1. Закрой Minecraft.
2. Убери BuildHelper из папки mods, если переходишь на обычную Litematica.
3. Удали старые версии Litematica и MaLiLib из mods, чтобы не было дубликатов.
4. Положи ОБА файла JAR в .minecraft/mods/
5. Запусти профиль Fabric для Minecraft 1.21.1.

Схемы .litematic клади в .minecraft/schematics/
Открыть меню Litematica: M (клавиша в английской раскладке).
Загрузить схему: M → Load Schematics → выбрать файл → Load Schematic.
В архиве фермы Iron_Farm_Wotpack_Java_1.21.1.zip используй файл .litematic.

MaLiLib обязательна: Litematica 0.19.61 требует MaLiLib 0.21.10 или новее.
Нужные модули Fabric API включены в этот файл MaLiLib.
Если полный Fabric API уже установлен для других модов, оставь его.

Официальные файлы без изменения содержимого; переименованы только JAR.
Проверены SHA-512, целостность архивов и fabric.mod.json.
Запуск игрового клиента в этой среде не выполнялся.
